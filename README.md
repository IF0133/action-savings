# 人生貯金 — Action Savings

どんなに小さくても、行動したらコインを一枚。
日々の行動をブタの貯金箱に貯め、一週間ごとに開けて振り返るアプリです。

## 使い方

1. 「貯める」で活動を選び、任意でメモを添えます。
2. コインを上へすべらせるか、タップして貯めます。
3. 週が終わってから戻ると貯金箱が登場します。タップして開封するか、演出をスキップできます。
4. 「コレクション」で週・コインを選んで振り返ります。「記録」では活動、メモ、カレンダーで検索できます。
5. 「設定」から使い方を実際に操作して練習できます。練習は本当の記録に影響しません。

活動は5種類。名前と色を変更でき、名前変更時は同じ活動の継続か、新しい用途かを選べます。
メモ候補は活動別の最近の履歴と初期テンプレートから最大5件表示します。横にスワイプして選べます。
長い活動名やメモ候補は省略表示されますが、保存内容は全文のままです。
投入後は7秒間「取り消す」を選べます。「×」で通知だけ閉じることもできます。
日付は日本時間の午前3時区切り。一週間は日曜午前3時から翌日曜午前3時までです。

## 効果音

投入、ブタの5種類の反応とレア反応、開封、コイン選択に短い効果音があります。
「設定」でオン／オフと音量を変更できます。初期音量は100%、調整範囲は0〜200%。音は操作後に再生されます。
オリジナルの合成音をブラウザ内で生成し、音源のダウンロードは行いません。
端末・ブラウザの消音設定で鳴らない場合も、アプリは利用できます。

## 大切なデータについて

- 記録は利用中のブラウザのIndexedDBに保存されます。GitHubに記録やメモを送信する機能はありません。
- アカウント、端末間の自動同期、クラウドバックアップはありません。
- ブラウザのサイトデータ削除などで失われる可能性があります。設定から定期的にJSONバックアップを書き出してください。
- 復元は現在の全記録・活動設定を置き換えます。音量設定はバックアップには含まれません。
- 別ブラウザ・別端末・ローカル版からの移行には、人生貯金形式のバックアップが必要です。
- Galton Logとは別アプリです。Galton Log形式のバックアップとは互換性がありません。
- 完全オフラインでの起動は保証していません。初回や更新時には通信環境が必要です。

より詳しい説明は [使い方・データの保存](./life-guide.html) を参照してください。

## このリポジトリ

アプリのビルド済み配布ファイルのみを置くためのリポジトリです。
開発用Dartソース、Flutter SDK、個人のバックアップは含みません。
ただし、配信するJavaScriptやWeb素材はブラウザから閲覧できます。
Flutter等の依存ライブラリのライセンス表示は配布物の `assets/NOTICES` に含まれます。
